# Context Brief

AI isn't short on brains. It's short on context.

Most people type one line into Claude and get an average answer back. The same people can explain their business all day long to a new starter. This kit gets you to brief Claude exactly like that: talk it through out loud, like you're talking to someone who just started in your team, and let Claude turn it into a proper brief before it does the work.

## What's in it

- **The Context Brief skill** for Claude Code and Codex. Say "Let me brief you", talk it through, and it shows your brief back in one clean block, asks only the questions that would change the result, then does the job. It can save the business part so you never say it twice (only if you say yes).
- **The new-starter brief**: the three things to cover every time.
  1. What the business does and who the customer is.
  2. The job you want done, and exactly how it looks when it's done.
  3. What's gone wrong before, and how to avoid it next time.
- **A copy-paste brief template** that works in any AI chat, no install needed: [brief-template.md](skills/context-brief/references/brief-template.md).
- **Wispr Flow setup**, so you can talk instead of type: [wispr-flow.md](skills/context-brief/references/wispr-flow.md).

**You need:** Claude Code or Codex for the skill. The template works anywhere. Dictation is optional; typing works too.

## Install

Copy the prompt in [SETUP-PROMPT.md](SETUP-PROMPT.md) into a new Claude Code or Codex session. Then start a new session and say:

> Let me brief you

## Just want the template?

Open [brief-template.md](skills/context-brief/references/brief-template.md), copy the box, fill it in (or say it out loud), and paste it at the top of any chat.
