# Setup prompt

Copy the block below into a new **Claude Code** or **Codex** session and press Enter.

```text
https://github.com/Mr-heka/context-brief

Install the Context Brief skill from this repository for me.

1. If the folder ~/context-brief exists, update it with: git -C ~/context-brief pull
   Otherwise download it with: git clone https://github.com/Mr-heka/context-brief ~/context-brief
2. Open ~/context-brief/SETUP.md and follow it to the end. Run every command yourself.
```

It takes under a minute. When it's done, start a new session and say **"Let me brief you"**.

To update later, paste the same block again.
